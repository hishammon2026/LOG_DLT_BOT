# 🧹 Automatic Join Message Remover

ഈ ബോട്ട് നിങ്ങളുടെ ടെലിഗ്രാം ഗ്രൂപ്പുകളിലോ ചാനലുകളിലോ അഡ്മിൻ ആക്കിയാൽ ഉടൻ തന്നെ പഴയതും പുതിയതുമായ ജോയിൻ മെസ്സേജുകൾ ഡിലീറ്റ് ചെയ്യുന്നു.

## 🌟 ഫീച്ചറുകൾ
- **Plug & Play:** അഡ്മിൻ ആക്കിയാൽ ഉടൻ പ്രവർത്തനം തുടങ്ങും.
- **Auto Status:** അഡ്മിൻ ആക്കിയ ഉടൻ ഗ്രൂപ്പിൽ മെസ്സേജ് അയക്കുന്നു.
- **Deep Clean:** 1000 മെസ്സേജുകൾ വരെ പഴയ സർവീസ് മെസ്സേജുകൾ ക്ലീൻ ചെയ്യുന്നു.
- **String Session No Needed:** ബോട്ട് ടോക്കൺ മാത്രം മതി.

## 🛠 എങ്ങനെ ഉപയോഗിക്കാം?
1. `API_ID`, `API_HASH`, `BOT_TOKEN` എന്നിവ നൽകുക.
2. ബോട്ട് റൺ ചെയ്യുക.
3. ഏതെങ്കിലും ചാനലിൽ അഡ്മിൻ ആക്കുക.
